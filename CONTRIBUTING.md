# Contributing to Tab Settings Enhanced

Thank you for your interest in contributing! 🎉

## How to Contribute

### Reporting Bugs
1. Check if the issue already exists
2. Create a new issue with:
   - Obsidian version
   - Plugin version
   - Steps to reproduce
   - Expected vs actual behavior
   - Screenshots if applicable

### Suggesting Features
1. Open a new issue with `[Feature Request]` prefix
2. Describe the feature and use case
3. Explain why it would be valuable

### Code Contributions

#### Setup
```bash
# Fork and clone the repository
git clone https://github.com/YOUR_USERNAME/tab-settings-enhanced.git

# Install dependencies
npm install

# Build
npm run build

# Development mode
npm run dev
```

#### Development Workflow
1. Create a feature branch: `git checkout -b feature/your-feature`
2. Make your changes
3. Test thoroughly
4. Commit with clear messages
5. Push and create a Pull Request

#### Code Style
- Use TypeScript
- Follow existing code patterns
- Add comments for complex logic
- Keep functions focused and small

#### Testing
1. Install the built plugin in a test vault
2. Test all existing features still work
3. Test your new feature/fix
4. Test on both light and dark themes

### Documentation
- Update README if adding features
- Update CHANGELOG for all changes
- Add JSDoc comments for new functions

## Code of Conduct

- Be respectful and inclusive
- Provide constructive feedback
- Focus on the code, not the person

## Questions?

Feel free to open an issue or reach out!
